This page talks to a local server that runs the extraction pipeline on this machine. Opened as a file it cannot reach it.

Start the server from the repository root and open the address it prints:

python app/server.py
Floor plan workflow app: http://127.0.0.1:8765/

Plans are processed locally and are not uploaded anywhere.

fpxFloor plan extraction /

How this works

  1. Upload one sheet per floor plan (PDF, JPG, PNG, TIFF, DXF), or try the demo sheet. The drawings, title block and notes are found within seconds, without text recognition.
  2. Building area: confirm the detected outline of the floor plan. Drag the handles so the whole building is inside and the title block, legend and dimension chains stay out.
  3. Scale: check the scale read from the notes, a scale bar or the dimension strings, and the resolution. If nothing was found, or the value looks wrong, measure a known distance on the drawing.
  4. Results: the extraction starts when the scale is confirmed and the walls, openings, stairs and rooms appear on the plan as they are found (about a minute per sheet, mostly text recognition). Then review the rooms, tick the ones you checked, and download the JSON, Excel, DXF, IFC, CSV or PNG from the Download menu.

Everything runs locally in app/data/ (gitignored). Nothing is uploaded anywhere.
