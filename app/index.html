How this works

  1. Upload one sheet per floor plan (PDF, JPG, PNG, TIFF, DXF). The pipeline normalises the file, reads the text, finds the drawings on the sheet and proposes a scale for each one.
  2. Building area: confirm the detected outline of the floor plan. Drag the handles so the whole building is inside and the title block, legend and dimension chains stay out.
  3. Scale: check the scale read from the notes, a scale bar or the dimension strings, and the resolution. If nothing was found, or the value looks wrong, measure a known distance on the drawing.
  4. Run: check the confirmed drawings, then run the extraction (walls, openings, stairs, rooms, areas, QA). About one minute per sheet on this machine, mostly OCR.
  5. Results: review the rooms, tick the ones you checked, and download the JSON and the DXF.

Everything runs locally in app/data/ (gitignored). Nothing is uploaded anywhere.
